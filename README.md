# sca-usd-export 0.1.8rc2

Download the **plugin ZIP** and `SHA256SUMS.txt` from the [v0.1.8rc2 Pre-release](https://github.com/PhySpace/sca-usd-export/releases/tag/v0.1.8rc2). GitHub's automatic **Source code** archives are source snapshots. Follow the [download, hash verification, extraction and SCA installation guide](docs/release-installation.zh-CN.md); SDK2.2.5 installs the extracted directory, not the ZIP. Source remains on `main`. Companion: [physics v0.1.8rc1](https://github.com/wwlloo/sca-physics/releases/tag/v0.1.8rc1). This is an rc pre-release, not a stable release.

Independent SCA2.2.5 product-package exporter. Packages without saved physics can be exported without installing sca-physics. Saved metadata.sca_physics and deformable preparation require the optional, exact sca-physics==0.1.8rc1 implementation. Reads physics schemas1.0–1.8 and directly generates segments, mass/inertia, D6/endpoint joints and collision policies from saved effective values. Schema1.8 adds sourced ordinary-joint limits, force actuators, articulation parameters and ideal angular-to-linear mimic coupling. See [joint actuator units and limitations](docs/joint-actuators.zh-CN.md), including passive/active damping combination and runtime SI target updates. Agent decisions and verified derivations are preserved; presets and segment counts are never recomputed on export. Optional input SHA256 and required-physics guards protect the selected final package. Runtime entrypoints compare installed business code with the payload before importing it. See [rc2 dependency and compatibility boundaries](docs/release-0.1.8rc2.zh-CN.md).

Read [Chinese installation and usage](README.zh-CN.md), [automatic cables](docs/automatic-cables.zh-CN.md), [release boundaries](docs/RELEASE-NOTES.zh-CN.md) and [historical rc1 validation](docs/VALIDATION-0.1.6rc1.zh-CN.md). An optional bounded Isaac runtime smoke entry checks initialization/short motion, not material calibration or theoretical precision. Old rc2 strict mechanics limitations remain; accepted phase delivery is not a retroactive accuracy pass.

Use the [Agent decision workflow](docs/agent-decisions.zh-CN.md) and [task runtime checker](docs/runtime-task-validation.zh-CN.md) for isolated installation, saved provenance, independent export and explicit task criteria. The corresponding Pre-release notes record the actual GitHub attachment download/install verification result; local software checks alone do not establish it.

The tested candidate pair is **sca-usd-export 0.1.8rc2 + sca-physics 0.1.8rc1**, on Windows x86-64, CPython 3.12.15, SCA SDK 2.2.5, OpenUSD/usd-core 26.8 and OCP 7.9.3.1 (NumPy 2.3.1, Plotly 7.1.0). Geometry users only need USD; physical workflows require the exact optional peer. Prepare physics 0.1.8rc1 first, update USD, then run provision with the explicit `SCA_PHYSICS_SOURCE` before writing new physics assets. Updating a payload always requires reprovisioning. See the [compatibility and upgrade matrix](docs/compatibility-0.1.8rc2.zh-CN.md) for verified inputs, commands and deployment paths.

Selected 2026-10-19 physics 0.1.0/schema 1.0 and 2026-10-20 physics 0.1.3rc1/schema 1.1 assets passed read/reload/export, as did the old path and in-memory `export_package` calls and JSON `ExportConfig`. **Old bare parameters without provenance are incompatible unchanged; the tested case passes after adding truthful source information.** The executable migration example is the paired physics repository's `examples/pendulum/physics-input.json`; preserve values and units, and provide `source.kind/detail` (plus real citation/conditions for reference sources), rather than inventing provenance. Earlier GitHub `9fa527b` defaulted to Y-up and restitution 0; current metadata-free defaults are Z-up and 0.1. Use explicit configuration when those earlier defaults are required.

`pyproject.toml` separates required export dependencies, the exact optional `physics` extra, the full `test` extra, and the Hatchling build dependency. Isaac/PhysX is an external simulation environment. The tested short state roots are `personal-workspace/results/arp-20261025-162555/s` (standalone) and `/p` (paired); their add-on homes are `s/a` and `p/a`. Deep runtime paths failed dependency installation with Windows WinError206. Two external CAD-FEM fixture checks, Isaac/PhysX behavior, other environments and all historical version combinations remain unverified; static USD validation does not establish simulation behavior or precision.
