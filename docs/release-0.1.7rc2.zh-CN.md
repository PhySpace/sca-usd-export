# 0.1.7rc2 配套变更与边界

配套依赖为 `sca-physics==0.1.7rc2`；支持 SCA 2.2.5、Windows x86-64、Python 3.12。
支持读取物理 Schema 1.0–1.7；新来源合同见 [Agent 决策流程](agent-decisions.zh-CN.md)。

- physics 的调用者决定与逐值来源进入最终包，导出器不重新猜材料、用途或 N。
- `export` 可要求最终包 SHA256 匹配和必须包含物理配置。旧调用的默认行为保持兼容。
- 安装入口在业务导入前核对 payload/runtime 文件集合、哈希、版本、解释器及配套 physics。
  只更新 payload 后必须 provision；同版本号不能代替字节身份。
- 配套部署提供隔离 stage、受保护的默认同步、旧 registry 私有技能改绑和恢复记录。
- 原生运行增加任务判据与外层证据核对。原数值守卫保留；10 m/s 属工程诊断警戒，
  不能单独证明物理错误。任务模式的继续策略须在运行前选择。

本次没有改变 Capsule/D6 力学映射。圆截面、平面初态、直线自然态、不可伸长近似、
逐关节阻尼、碰撞过滤及深灰动态代理仍是当前表示边界。选段辅助是初始工程估算，
没有运行误差自适应。有限运行检查不等于材料标定、分段无关性、扭转精度或真实甩绳验证。
历史大链/480 Hz 失败及精度对照保持原记录。

发布版本号描述工作树目标，不证明远程发布验收完成。交付前须纳入新增文件、审查
差异并建立提交；本版本开发流程不自动提交或推送 Git。实际安装、案例与仿真结果以
相应任务生成的源码身份清单和运行报告为准。
